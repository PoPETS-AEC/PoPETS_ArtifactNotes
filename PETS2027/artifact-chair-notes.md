Number of reviews per badge, suggestion: available (1 or 2), functional (2), reproduced (2 or 3)

Assign discussion leads for each artifact to ensure that artifact evaluation is moving along?

Comments on artifact template:
- capitalization of some titles to harmonize
- check if we have ssh git clone instructions (and if so, replace by HTTPS to avoid issues when users are not logged in)

Preliminary and finalized deadlines were appreciated by both authors/reviewers
Very important to keep preliminary review deadline to identify issues early on (with artifacts, or authors/reviewers not responsive)

For PETS 2027: increased scrutiny into the reasons given by authors for not submitting their artifact with paper submission.

For PETS 2028: suggestion to make artifact submission (for available badge) mandatory

Some reasons given by authors for not submitting or only applying for available badge:
- student graduated, another student or advisor had to package code (poor anticipation)
- not familiar with virtualization/containerization so just released as available
- (incorrect) impression that community does not value artifact badges or coming from another community where artifact evaluation does not exist

PETS PC chairs are not rotating every other year anymore: each year, someone new is picked, we could reconsider for artifact chairs too if the continuity is needed or if we can do it differently (with discussion lead model).

## For each artifact issue
1. Share call for artifact with PC chairs so that they can invite authors of accepted papers and conditional invite to papers with revision
2. Have submission server ready to accept submissions
3. Invite new reviewers as needed, communicate to reviewers deadlines and other instructions as needed
4. Receive definitive list of accepted papers from PC chairs for this issue (so that we can track across the year, which authors delay submission to later artifact issue)
5. Send bidding instructions
6. At same time, artifact chairs should make a quick pass on submissions and ping authors if material missing, incorrect links, etc. (help speed up the evaluation if these issues are resolved early, some reviewers will also flag some things when bidding).
7. Perform review assignment, add final link field to submission form
8. Keep track of evaluation process, answer questions and concerns, help where needed, ping authors/reviewers, assign badges and collect final links
9. Collect links, update websites, send stats/thank you to reviewers
